# 롯데월드 1114 여행수첩

둘이서 쓰는 롯데월드 하루 기록 앱입니다. 지출 정산, 일정, 놀이기구 48종 체크, 지도와 현재 위치를 담았습니다.
서버 없이 동작하고, 기록은 각자 폰의 브라우저에 저장됩니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. (예: `lotteworld-trip`, Public)
2. 이 폴더의 파일을 **폴더 구조 그대로** 전부 올립니다.
   `Add file → Upload files`에 압축을 푼 내용물을 통째로 끌어다 놓으면 됩니다.
   (`index.html`이 저장소 맨 위에 있어야 합니다. `.nojekyll`도 같이 올려 주세요.)
3. 저장소 `Settings → Pages`에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 고르고 Save.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 주소로 열립니다.

## 폰에 앱처럼 설치하기

- **안드로이드 (Chrome)**: 주소를 연 뒤 메뉴 `⋮ → 홈 화면에 추가` (또는 `앱 설치`)
- **아이폰 (Safari)**: 공유 버튼 `→ 홈 화면에 추가`

설치한 뒤 한 번 열어 두면 인터넷이 느려도 앱 화면은 열립니다. 지도 그림은 한 번 본 구역만 저장됩니다.

## 알아둘 점

- 현재 위치는 `https` 주소에서만 동작합니다. GitHub Pages는 https라서 괜찮습니다.
- 처음 "현재 위치 켜기"를 누르면 브라우저가 위치 권한을 묻습니다. 허용해 주세요.
- 실내(어드벤처, 언더랜드)는 GPS 오차가 크고 층을 구분하지 못합니다. 야외인 매직아일랜드에서 가장 잘 맞습니다.
- 지도의 구역 표시 2개는 대략적인 위치입니다. 놀이기구별 위치는 현장에서 "핀 꽂기"로 직접 저장합니다.
- 기록은 폰마다 따로 저장됩니다. `합치기` 탭의 코드 복사/붙여넣기로 두 사람 기록을 합칩니다.
- 브라우저 데이터를 지우면 기록도 사라집니다. 중요한 기록은 코드로 백업해 두세요.
- 놀이기구 목록은 2026년 11월 기준으로 정리했습니다. 운휴, 키 제한, 대기시간은 롯데월드 공식 앱에서 확인하세요.
